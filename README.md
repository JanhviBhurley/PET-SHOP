 🐶 PETSHOP – Online Pet Utilities Store🐱 
PETSHOP is a web-based application developed using PHP and MySQL that allows users to browse and purchase pet products such as food, toys, accessories, and grooming supplies. The system provides a simple and secure online shopping experience for pet owners.
 Features
- User registration and login  
- Browse products by category  
- Product search and cart system  
- Online order placement  
- PayPal payment integration  
- Admin dashboard for product and order management  
 Technologies Used
- HTML, CSS, JavaScript  
- PHP  
- MySQL  

▶️ How to Run the Project
1. Install **XAMPP/WAMP Server**
2. Copy the project folder into the `htdocs` directory
3. Create a database in **phpMyAdmin**
4. Import the provided `.sql` file
5. Update database connection details in PHP files
6. Start Apache and MySQL
7. Open browser and run:
   http://localhost/petshop
